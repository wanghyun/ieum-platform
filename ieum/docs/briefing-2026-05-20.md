# 아이이음 1차 브리핑 흐름

## 목적

아이이음은 도장 운영자가 매일 반복하는 일을 줄이고, 학부모에게는 정리된 결과를 보여주는 도장 운영 OS를 목표로 한다.

## 오늘 보여줄 핵심 흐름

1. 학생 등록
   - 학생명과 보호자 연락처만으로 빠르게 등록한다.
   - 학생번호는 휴대폰 뒷자리로 자동 지정할 수 있다.
   - 인성리포트/체력리포트 사용 여부를 학생별로 제외할 수 있다.

2. 앱 출석기
   - 태블릿 앱에서 도장 연결 후 학생번호로 등원 처리한다.
   - 중복 등원은 안내하고, 정상 등원 시 문자 큐가 생성된다.
   - 등원 완료 후 다음 번호 입력을 바로 받을 수 있다.

3. 대시보드
   - 오늘 미등원, 장기 미등원, 생일자, 수련비 미납, 문자 실패, 차량 메모를 한 화면에서 확인한다.
   - 월말 리포트 마감 카드는 인성/체력 입력 완료와 발송/인쇄 준비 현황을 보여준다.

4. 수련비/문자
   - 수련비 납부 상태와 미납 문자를 관리한다.
   - 이미 발송한 미납 문자는 재발송 확인 팝업을 거친다.
   - 결제선생 연동 전까지는 청구 대상/제외 대상 기준을 먼저 안정화한다.

5. 인성 리포트
   - 부별 주간 입력을 기준으로 월간 인성 리포트를 만든다.
   - 지도진 특별 칭찬, 아이잘해 미션, 인성 레벨 흐름을 포함한다.
   - 4주차 입력 완료 학생만 전체 인쇄 대상이 된다.

6. 체력 리포트
   - 실제 측정값을 입력하면 학년/성별 기준으로 환산한다.
   - BMI는 점수에 포함하지 않고 성장 참고 정보로 표시한다.
   - 이번 측정 주기 대상 중 입력 완료 학생만 발송/인쇄 준비로 잡는다.

7. 차량
   - 차량/노선/정류장 등록, 학생별 등원/하원 배정, 차량 일지 인쇄가 가능하다.
   - 기사 앱은 탑승/미탑승/통화/메모 흐름을 Android에서 먼저 검증한다.

## 오늘 검증된 항목

- 월말 마감 주요 버튼 6개 동선 정상
- 체력 입력 완료 기준 수정: 빈 기록은 완료로 보지 않음
- 대시보드 체력 측정 카드: 실제 입력 완료 2/125명 반영
- 대시보드 발송/인쇄 준비 카드: 인성 0명, 체력 2명 기준으로 2/2명 반영
- 체력 전체 인쇄: 준비 원생 2명 A4 비율 미리보기 정상 로드
- 인성 전체 인쇄: 현재 준비 원생 0명 안내 정상
- 학생별 인성/체력 리포트 사용 여부 설정 확인
- Android 차량 기사 앱 디버그 빌드 및 USB 설치 성공
