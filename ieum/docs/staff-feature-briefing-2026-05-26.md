# 아이이음 도장운영 OS 직원 공유자료

## 한 줄 정의

아이이음은 태권도장과 예체능 교육기관이 출석, 문자, 수련비, 차량, 리포트, 승급 업무를 한 흐름으로 관리하는 도장운영 OS입니다.

## 핵심 방향

- 입력은 최소화합니다.
- 반복 업무는 자동화합니다.
- 관장님과 사범님은 오늘 해야 할 일만 빠르게 확인합니다.
- 학부모는 결과와 성장 흐름만 봅니다.
- 아이는 출석, 인성, 체력, 승급을 성장 경험으로 느낍니다.

## 사용자별 가치

### 본사

- 가맹점별 사용 현황을 확인합니다.
- 원생 수, 리포트 사용, 차량 사용, 결제 청구서 사용량을 봅니다.
- 결제선생, 지도 API, 문자 발송폰, 출석기 연결 상태를 관리합니다.
- 향후 승급 안내, 급증 용지, 띠 주문 같은 부가 수익 흐름을 연결합니다.

### 도장 관장님

- 하루 시작 전 대시보드에서 미등원, 생일자, 장기 미등원, 수련비, 문자 실패를 확인합니다.
- 학생 등록과 수정, 출석, 수련비, 차량, 리포트, 승급을 한 곳에서 관리합니다.
- 월말에는 인성/체력 리포트 준비 대상과 미완료 항목을 확인합니다.

### 사범님

- 수업 부별로 출석과 인성 입력을 빠르게 처리합니다.
- 체력 측정은 실제 수치만 입력하고 점수 환산은 시스템이 처리합니다.
- 승급 심사 명단과 미션 체크표를 출력해 현장에서 사용합니다.

### 학부모

- 등하원 알림을 받습니다.
- 수련비 안내와 결제 링크를 받습니다.
- 월간 인성/체력 리포트, 승급 안내, 축하 메시지를 받습니다.

### 아이

- 등원 시 사진, 등급, 성장 메시지를 확인합니다.
- 인성 레벨, 아이잘해 미션, 체력 변화, 승급을 통해 성장 체감을 얻습니다.

## 주요 기능

### 학생/출석

- 학생 등록, 수정, 검색, 프로그램/부별 필터
- 엑셀 업로드/다운로드
- 앱 출석기 QR 연결
- 등원 저장, 중복 출석 방지, 문자 큐 생성
- 오늘 출석, 미등원 확인, 관리자 직접 출석 처리

### 문자/수련비

- 문자 발송폰 연결 관리
- 등하원 문자, 수련비 문자, 미납 문자 큐 관리
- 수련비 정책, 형제/자매 묶음 청구
- 자동 발송 대상에서 납부 완료 학생 제외
- 결제선생 API 연동 준비

### 인성 리포트

- 주간 인성 입력
- 기본 3점, 필요 시 4~5점 조정
- 지도진 특별 칭찬
- 성실 항목은 출석 기반 자동 반영
- 아이잘해 월간 미션 참여 체크
- 학부모용 월간 인성 리포트와 장기 성장 리포트
- 인성 레벨과 다음 레벨까지 남은 점수 표시

### 체력 리포트

- 키, 몸무게, BMI 입력
- 줄넘기, 셔틀런, 팔굽혀펴기, 윗몸일으키기, 제자리멀리뛰기, 유연성 등 실제 수치 입력
- 학년/성별 기준 자동 환산
- 도장별 체력 항목 커스텀
- 일괄 인쇄와 문자 발송 준비

### 차량

- 차량, 노선, 운행 지점 등록
- 학생별 등원/하원 차량 배정
- 기사님 모바일 탑승 확인
- 탑승, 미탑승, 통화, 메모 기록
- 차량 메모 대시보드 확인
- 네이버 지도 API 기반 정류장/위치 보조

### 승급/승품단

- 18급부터 1급, 1품/단 흐름 관리
- 승급 대상과 승품/단 대상 분리
- 도장별 승급 기간 설정
- 띠 순서와 급 범위 설정
- 이번 달 준비해야 할 띠 수량 확인
- 승급 미션 체크표 인쇄
- 급증 인쇄
- 심사 안내문 선택 인쇄와 문자 발송
- 심사비와 입금 계좌는 승급 설정에서 관리

### 본사 관리

- 가맹점 등록/승인
- 가맹점별 원생 현황과 기능 사용량 확인
- 결제선생/지도 API 설정
- 문자폰, 출석기, 차량, 리포트 사용 신호 확인
- 새벽 자동 집계와 수동 갱신

## 수익화 연결 포인트

- 결제선생 청구서 발송 자동화
- 승급/승품단 심사 안내 카톡/문자 자동화
- 급증용 금박 A4 배경지 판매
- 띠 수량 자동 계산 후 향후 주문 연결
- 인성/체력/장기 성장 리포트 기반 프리미엄 운영 상품화

## 현재 브리핑 포인트

- 아이이음은 단순 출석 앱이 아니라 도장운영 OS입니다.
- 매일 보는 화면은 대시보드와 오늘 출석입니다.
- 학생관리는 명부와 빠른 수정 화면입니다.
- 리포트는 학부모 만족용이면서 도장 운영 차별화 자료입니다.
- 승급은 현장 업무를 줄이면서 본사 수익화까지 연결할 수 있는 카테고리입니다.

## 직원들과 확인할 질문

- 관장님이 매일 가장 먼저 보는 화면은 충분히 단순한가?
- 학생 100명 이상일 때 등록, 수정, 검색이 피곤하지 않은가?
- 문자 발송 실패나 미등원처럼 놓치면 안 되는 업무가 잘 보이는가?
- 인성/체력/승급 리포트는 인쇄와 문자 발송 둘 다 자연스러운가?
- 유료화 또는 부가 수익으로 연결되는 기능이 억지스럽지 않은가?
