# 아이이음 도장 운영 OS 1차 브리핑

일시: 2026-05-18 16:00 예정  
대상: 회사 내부 직원 1차 공유

## 1. 현재 방향

아이이음은 단순 출석 프로그램이 아니라 관장님이 매일 쓰는 도장 운영 OS로 개발한다.

핵심 방향은 다음 3가지다.

- 관장님 입력은 줄이고, 운영 판단은 자동으로 보이게 한다.
- 학부모에게는 도장이 제공하는 성장 자료와 알림이 깔끔하게 전달되게 한다.
- 아이는 출석, 인성, 차량, 리포트 흐름에서 성장 체감을 느끼게 한다.

## 2. 현재까지 1차 완성된 큰 기능

### 학생/출석

- 학생 등록, 수정, 프로그램별 분류
- 태권도/합기도/줄넘기 프로그램 구분
- 수업 부별 학생 관리
- 출석 저장 및 중복 출석 방지
- 태블릿/앱 출석기 연결 구조
- 출석 후 학생 사진, 수련 흐름, 인성 레벨 표시 방향 반영

### 문자 발송

- 출석 문자 큐 생성
- 도장별 문자 발송폰 연결
- 문자 발송폰 앱 설치 및 연결 코드 방식
- 도장별 자동 발송 요일/시간 설정
- 문자 발송폰 앱은 도장 전용 APK 설치 방식으로 운영
- Google Play에는 SMS 발송 앱이 아니라 향후 관리자/출석/차량 앱 중심으로 접근

### 수련비/청구

- 수련비 정책
- 학생별 수련비 자동 반영
- 형제/자매 청구 흐름
- 자동 발송 및 미납 포함 청구 방향
- 결제선생/PAYMINT 연동 준비 구조
- 본사 충전금/도장별 청구서 발송 사용량 추적 방향

### 차량

- 차량/노선/운행 지점 등록
- 학생별 등원/하원 차량 배정
- 차량 일지 출력
- 기사님 모바일 탑승 확인 화면
- 탑승/미탑승/통화/메모 흐름
- 네이버 지도 API 연동 준비 및 일부 반영

### 인성 리포트

- 주간 인성 입력 구조
- 부별 입력 방향
- 학부모용 월간 인성 리포트
- 아이잘해 미션 반영
- 인성 레벨/누적 성장 방향 반영
- 장기 인성 성장 리포트 방향 설정

## 3. 아직 시작 전 또는 미완성 핵심

### 체력 리포트

아직 본격 구현 전이다. 반드시 별도 구간으로 잡아야 한다.

예정 방향:

- 월 1회 숫자 입력
- 줄넘기, 왕복달리기, 팔굽혀펴기, 윗몸일으키기, 제자리멀리뛰기, 유연성
- 출석 점수 포함 금지
- 기본 40점 + 6개 항목 환산
- 학부모에게는 점수보다 성장 그래프와 전월 대비 변화 중심으로 표시
- 인성 점수와 합쳐 게임 티어/월간 종합 리포트에 반영

## 4. 4시 브리핑에서 꼭 말할 포인트

- 아이이음은 관장님이 편하게 쓰는 운영 플랫폼이다.
- 리포트는 학부모용 결과물이지만, 본질은 도장 운영을 돕는 자동화 도구다.
- 문자 발송폰 앱은 Play Store 정책 때문에 도장 전용 APK 설치 방식이 현실적이다.
- 출석, 문자, 차량, 수련비, 인성 리포트는 1차 골격이 연결되었다.
- 체력 리포트와 월간 종합 리포트는 다음 핵심 구간이다.

## 5. 다음 개발 우선순위

1. 학생/출석 daily 화면 완성도 정리
2. 문자 발송폰 설치 UX 개선: QR 다운로드, 버전 확인, 업데이트 안내
3. 체력 리포트 1차 구현
4. 월간 종합 리포트: 출석 + 인성 + 체력 + 티어
5. 결제선생 API 실제 키 발급 후 샌드박스 연동
6. 차량 기사 앱 고도화 및 지도 기반 운행 흐름 정리
7. 내부 직원 테스트용 체크리스트 작성

## 6. 직원 테스트 시 확인할 것

- 신규 학생 등록이 빠른가
- 학생/출석 화면에서 필요한 정보만 보이는가
- 문자 발송폰 설치와 연결이 헷갈리지 않는가
- 차량 배정과 차량 일지가 실제 현장에서 쓸 만한가
- 인성 리포트가 관장님 설명 자료로 충분한가
- 체력 리포트가 빠져 있다는 점을 다음 개발 항목으로 명확히 이해했는가
