# 회원관리 개선 기획

작성일: 2026-06-03

## 현재 구현된 것

- 학생 목록에서 오늘 수업, 오늘 미등원, 장기 미등원, 아이들 메모, 생일, 연락처 누락, 차량 미배정, 수련비 미납, 리포트 발송 불가 조건을 볼 수 있다.
- 대시보드 오늘 알림 카드는 기본값을 `미등원`, `문자 실패`, `아이들 메모`, `장기 미등원`, `수련비 미납`, `월말 마감` 중심으로 두고 관장이 추가/제거할 수 있다.
- 장기 미등원처럼 확인 처리되는 신호는 대시보드에서 열린 항목만 보이도록 목록 이동을 보완했다.
- 수련비 미납과 오늘 납부일은 수련비 목록의 같은 필터로 이동한다.

## 보완 방향

1. 회원 프로필 상단에 `오늘 해야 할 일`을 고정한다.
   - 미등원 연락, 상담 메모, 연락처 보완, 수련비 확인, 리포트 발송 불가를 한 줄 액션으로 보여준다.

2. 학생 목록의 신호를 `위험`, `주의`, `확인`으로 정리한다.
   - 위험: 장기 미등원, 리포트 발송 불가, 수련비 미납
   - 주의: 오늘 미등원, 연락처 누락, 차량 미배정
   - 확인: 생일, 메모, 오늘 수업

3. 케어 기록을 누적한다.
   - 누가, 언제, 어떤 연락을 했는지 남기고 다음 방문 때 같은 학생을 다시 확인할 수 있어야 한다.

4. 수련비와 회원관리를 연결한다.
   - 미납 학생을 단순 금액이 아니라 `연락 필요`, `납부 예정`, `확인 완료` 상태로 관리한다.

5. 대시보드 카드는 목록과 같은 기준을 사용한다.
   - 카드 숫자, 클릭 후 목록, 확인 처리 후 숫자가 같은 흐름으로 움직여야 한다.

## 추천 작업 순서

1. 학생 목록 필터 문구와 정렬 기준을 정리한다.
2. 회원 프로필 상단에 다음 행동 영역을 추가한다.
3. 케어 기록 저장 화면을 단순하게 만든다.
4. 수련비 미납 상태 메모를 학생 프로필에 연결한다.
5. 대시보드 카드 설정 화면에서 카드별 설명을 함께 보여준다.

## 운영 원칙

- 메인 화면은 “장사 지표”가 아니라 “오늘 도장에서 처리해야 할 일”을 보여준다.
- 중복 카드는 줄이고, 같은 데이터는 한 곳에서 보고 필요한 화면으로 이동한다.
- 숫자는 반드시 클릭했을 때 같은 기준의 목록으로 이어져야 한다.
