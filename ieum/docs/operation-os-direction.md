# 아이이음 도장운영 OS 진행 방향

## 핵심 기준

아이이음은 리포트 서비스가 아니라 도장 운영을 덜 피곤하게 만드는 운영 OS다.
관장님과 사범님이 처음에는 가볍게 시작하고, 쓰다 보면 출석, 문자, 수련비, 차량, 인성 기록이 자연스럽게 연결되어야 한다.

## 화면별 역할

### 대시보드

하루 시작 전에 보는 운영 알림판이다.
직접 처리 화면이 아니라, 오늘 위험 신호와 바로 가야 할 업무를 알려준다.

- 미등원, 문자 실패, 수련비 확인, 차량 메모, 장기 미등원, 생일자
- 처음 쓰는 도장 흐름 또는 도장별 자주 쓰는 바로가기
- 자동 체크 신호

### 오늘 출석

수업 중 실시간으로 보는 화면이다.
오늘 수업 대상, 등원, 미등원, 수업일 상태, 차량/수련비/생일 신호를 현장 기준으로 보여준다.

### 학생 관리

학생 정보를 빠르게 등록하고 수정하는 명부 화면이다.
수련비 미납, 차량 배정, 리포트 발송 같은 업무를 이 화면에 과하게 넣지 않는다.

- 신규 등록
- 학생명 클릭 후 빠른 수정
- 리스트 검색/필터/페이지
- 일괄 변경

### 수련비/문자

돈과 알림이 연결되는 업무 화면이다.
자동 청구, 미납 발송, 문자 상태, 결제선생 연동은 이 영역에서 관리한다.

### 차량

차량을 매일 쓰는 기사님과 관리자가 분리되어야 한다.

- 오늘 탑승: 기사님/현장 확인
- 차량 배정: 학생별 등원/하원 배정
- 운행 관제: 위치와 특이사항
- 차량 일지: 인쇄/운행표
- 차량/노선 설정: 초기 설정

### 인성/성장

학부모에게 보여주는 리포트이면서, 관장님 입장에서는 도장 운영 차별화 자료다.
월간, 장기 성장, 아이잘해 미션이 연결되어야 한다.

## 다음 우선순위

1. 학생관리 실사용 마감
   - 학생관리는 명부와 빠른 수정 화면이다.
   - 신규 등록, 학생명 팝업 수정, 엑셀 이관, 프로그램/부 필터, 일괄 변경을 100~200명 기준으로 점검한다.
   - 수련비 미납, 차량 배정, 리포트 발송 같은 처리는 각 업무 화면으로 보내고 학생관리에는 신호를 과하게 넣지 않는다.

2. 오늘 출석/Daily 화면 마감
   - 오늘 출석은 수업 중 현장판이다.
   - 오늘 수업 대상, 등원, 미등원, 직접 등원 처리, 생일, 장기 미등원, 차량 메모, 수련비 신호를 하루 운영 기준으로 정리한다.
   - 대시보드는 하루 시작 전 알림판, 오늘 출석은 수업 중 확인판으로 역할을 나눈다.

3. 수련비/결제선생 준비
   - 형제·자매 묶음 청구, 자동 발송 제외 규칙, 미납 포함 청구를 먼저 확정한다.
   - 결제선생 API 적용 전 도장별 발송 로그, 결제 완료/실패, 본사 충전금 사용량 집계 구조를 준비한다.
   - 도장 관리자에게 발송비를 노출하지 않고, 본사 관리자만 사용량을 확인한다.

4. 차량 기사님 흐름
   - 차량은 관리자 설정 화면보다 기사님 실사용 화면이 중요하다.
   - 탑승, 미탑승, 통화, 메모, 전체 탑승 처리, 바로 전화 연결을 모바일 중심으로 다듬는다.
   - 네이버 지도는 정류장/노선 등록과 운행 관제의 보조 도구로 쓴다.

5. 월말 운영 루틴
   - 월말에는 관장님이 수련비, 장기 미등원, 상담 필요, 인성 입력 누락, 리포트 발송 대상을 한 번에 확인해야 한다.
   - 월간 인성리포트는 운영 플랫폼 안의 하나의 카테고리이며, 도장 사업장 운영에 도움이 되는 자동화 자료로 다룬다.

6. 인성/성장 상품성
   - 학부모용 월간 리포트는 A4 인쇄와 모바일 링크를 모두 고려한다.
   - 아이잘해 미션, 성장 레벨, 브론즈/실버/골드 등급, 6개월·12개월 종합 리포트를 연결한다.
   - 점수보다 변화, 참여, 다음 성장 목표가 눈에 보이게 한다.

## 1차 마감 기준

- 도장 관리자 계정으로 학생 100~200명을 등록/검색/수정할 수 있다.
- 기존 업체 원생 엑셀을 업로드하고, 확인 필요 항목을 정리한 뒤 학생관리로 반영할 수 있다.
- 태블릿 출석 앱에서 QR 연결 후 등원 처리와 중복 방지가 된다.
- 오늘 출석 화면에서 미등원, 직접 등원 처리, 문자 큐, 수업일 상태를 확인할 수 있다.
- 수련비 자동 발송 대상에서 미리 납부한 학생은 제외된다.
- 차량 탑승/미탑승/통화/메모가 관리자 화면에서 확인된다.
- 인성 입력과 월간 학부모 리포트 초안이 한 학생 기준으로 끝까지 이어진다.

## 제품 감각

처음 쓰는 도장은 “이 정도면 해볼 수 있겠다”를 느껴야 하고,
계속 쓰는 도장은 “이제 예전 방식으로 돌아가면 더 불편하다”를 느껴야 한다.
